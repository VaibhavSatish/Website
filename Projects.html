ZOTNest

React Python FastAPI Leaflet
A property search tool built at UC Irvine's 2026 Irvine Hacks, aimed at helping the university's 30,000+ students find housing. Maps 30+ listings with real-time clustering via Leaflet, ranks results with a multi-criteria filtering algorithm built around user preferences, and runs a Python pipeline that scrapes and parses 500+ Google Maps reviews into readable insights.
